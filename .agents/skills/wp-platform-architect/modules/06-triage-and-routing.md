# ماژول ۰۶: تریاژ، طبقه‌بندی و درخت تصمیم‌گیری پروژه‌ها (Triage & Decision Tree)

> **خاستگاه:** بهینه‌سازی و تطبیق اسکیل `wordpress-router`.

این ماژول در ابتدای هر تسک یا درخواست جدید بررسی می‌کند که با چه نوع نیازمندی در محیط وردپرس مواجه هستیم و کار را به زیرماژول یا ابزار صحیح هدایت می‌کند:

---

## ۱. درخت تصمیم‌گیری (Decision Tree)

```text
درخواست جدید مرتبط با وبسایت / وردپرس
│
├── آیا درخواست شامل استراتژی برند، نام‌گذاری، بریف برند، نشان تجاری، یا هویت کلامی است؟
│   └── بله ──> هدایت به اسکیل [/wp-brand-architect] و ماژول ۰۸
│               + ممیزی ۹ ایده‌آل ویلر + توالی شناخت (Shape -> Color -> Content)
│
├── آیا درخواست شامل ویرایش مستقیم بلوک‌های محتوا یا تغییر ساختار در گوتنبرگ است؟
│   └── بله ──> اولویت با اسکیل رسمی [/edit-wordpress-block-content] یا [/publish-wordpress-content]
│               + رعایت ماژول ۰۲ (عدم استفاده از wp:html خام)
│
├── آیا نیاز به ایجاد برگه جدید یا رفع نواقص تمپلیت‌های خام (مثل پروژه‌ها یا حریم خصوصی) است؟
│   └── بله ──> استفاده از ماژول ۰۱ و ۰۲ (ساخت page-*.php در machinedesign-theme)
│               + گیت ۰ (0.00px تقارن، عدم استفاده از ایموجی، حفظ سطوح سفید)
│
├── آیا درخواست نیازمند ارسال استعلام، فرم، وب‌هوک، یا کوئری دیتابیس است؟
│   └── بله ──> استفاده از ماژول ۰۳ (افزونه RFQ / روت‌های REST API / بهینه‌سازی دیتابیس)
│               + رعایت ماژول ۰۵ (تراکنش‌های دیتابیس با UTF-8mb4 در PHP)
│
└── آیا تغییرات ظاهری، CSS یا بصری مورد نیاز است؟
    └── بله ──> بررسی تعلیق T036 (عدم دستکاری سکشن‌های سفید)
                + استخراج استایل‌های اینلاین به فایل style.css
                + بررسی تعادل آکولادها و اجرای lint.mjs
```

## ۲. ران‌بوک پاسخ به خطاهای رایج

1. **خطای `box-shadow: none;` در لینتر Gate 0:**
   * این یک باگ شناخته‌شده در رجکس لینتر است. راه‌حل: نوشتن `box-shadow: none !important;` یا استفاده از کامنت `/* taste-skill-ignore */` روی همان خط.
2. **خطای `font-mono` در لینتر:**
   * نام توکن CSS را به `--font-tech` تغییر دهید تا فونت برند `JetBrains Mono` حفظ شود و لینتر پاس گردد.
3. **عدم بازتاب تغییرات CSS در مرورگر:**
   * فایل `functions.php` از `filemtime` برای Cache-Busting استفاده می‌کند. در صورت کش شدن استایل‌ها در مرورگر، صفحه را با `Ctrl + F5` رفرش کامل کنید.
